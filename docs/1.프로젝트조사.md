PRD 작성을 위한 사전 조사를 수행해줘.

[기술 조건]
- 프론트엔드는 React + JavaScript로 구현한다.
- TypeScript를 사용하지 않는다.
- .ts와 .tsx 파일을 생성하거나 수정하지 않는다.
- TypeScript 관련 패키지와 설정을 추가하지 않는다.

[코드 조사]
1. 프론트엔드 루트 디렉터리
2. React와 빌드 도구의 실제 버전
3. 현재 사용하는 JavaScript 및 JSX 파일 확장자
4. ESLint와 JavaScript 검사 설정
5. 라우팅 방식과 버전
6. 상태 관리 방식
7. API 호출 방식
8. CSS 또는 UI 라이브러리
9. 기존 공용 컴포넌트와 디자인 토큰
10. 테스트 도구와 실행 명령
11. 린트와 프로덕션 빌드 명령
12. 기존 백엔드 API 호출 위치와 확인 가능한 계약
13. 인증과 권한 처리 방식

[UI 이미지 조사]
프로젝트의 ui설계도.png를 직접 열어 분석해줘.

다음 내용을 구분해서 보고해:
- 이미지에서 명확하게 확인되는 화면 구조
- UI 요소와 표시 텍스트
- 색상, 정렬, 간격 및 시각적 계층
- 재사용 가능한 컴포넌트 후보
- 이미지에서 확인할 수 없는 인터랙션
- 이미지에서 확인할 수 없는 반응형 동작
- 이미지에서 확인할 수 없는 로딩, 빈 결과, 오류 상태

[Context7 검증]
- package.json과 lock 파일에서 실제 라이브러리 버전을 확인한다.
- React와 사용 중인 라이브러리의 JavaScript 사용법을 Context7로 조회한다.
- 프로젝트 버전에 맞는 문서만 사용한다.
- TypeScript 예제를 그대로 가져오지 않는다.

[금지 사항]
- 어떤 파일도 수정하지 않는다.
- 패키지를 설치하지 않는다.
- TypeScript 도입을 제안하지 않는다.
- 이미지에 없는 기능을 추측하지 않는다.
- 존재가 확인되지 않은 API를 가정하지 않는다.

조사 결과, Context7 조회 내용, 확인된 제약 및 추가 질문만 제출해.
아직 PRD나 코드를 작성하지 마.

use context7
