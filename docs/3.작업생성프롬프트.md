승인된 PRD를 기반으로 프론트엔드 작업 목록을 생성해줘.

저장 경로:
tasks/tasks-prd-[feature-name].md

규칙:
1. React + JavaScript만 사용한다.
2. 파일 확장자는 기존 규칙에 따라 .jsx 또는 .js를 사용한다.
3. .ts와 .tsx 파일을 생성하거나 수정하지 않는다.
4. TypeScript 관련 설정이나 패키지를 추가하지 않는다.
5. 백엔드 파일과 API 계약을 변경하지 않는다.
6. 각 작업에 연결된 FR 번호를 표시한다.
7. 각 작업에 생성 또는 수정할 예상 파일을 표시한다.
8. ui설계.jpg와 기존 디자인 시스템을 기준으로 한다.
9. 접근성, 반응형, 오류 상태 및 테스트 작업을 포함한다.
10. 라이브러리 사용법은 Context7에서 JavaScript 기준으로 확인한다.
11. 새로운 패키지가 필요하면 작업을 Blocked로 표시한다.
12. 마지막 작업에는 ESLint, 테스트, 프로덕션 빌드 검증을 포함한다.
13. TypeScript 타입 검사 작업은 포함하지 않는다.
14. 아직 구현하지 않는다.

다음 구조로 작성해:
- Relevant Files
- Constraints
- Context7 References
- Tasks
- Requirement Traceability
- Blocked / Open Questions

먼저 전체 작업 목록을 보여주고 승인을 기다려라.
