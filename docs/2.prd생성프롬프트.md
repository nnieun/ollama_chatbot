사전 조사 결과와 내 답변을 바탕으로 React 프론트엔드 PRD를 작성해줘.

저장 경로:
tasks/prd-[feature-name].md

[기술 제약]
- React + JavaScript만 사용한다.
- TypeScript를 사용하지 않는다.
- 컴포넌트 파일은 기존 프로젝트 규칙에 따라 .jsx 또는 .js를 사용한다.
- .ts 및 .tsx 파일을 생성하거나 수정하지 않는다.
- tsconfig.json 또는 TypeScript 패키지를 추가하지 않는다.
- 타입 안정성이 필요한 외부 데이터는 기존 프로젝트 방식으로 검증한다.
- 기존 방식이 없다면 런타임 검증 도입 여부를 Open Questions에 기록하고
  승인 없이 패키지를 추가하지 않는다.

PRD에 포함할 내용:
1. 개요
2. 목표
3. 사용자 스토리
4. 화면 구조
5. ui설계.jpg에서 확인된 UI 요구사항
6. 기능 요구사항
7. API 연동 요구사항
8. 로딩, 빈 결과, 오류 상태
9. 접근성 요구사항
10. 반응형 요구사항
11. 테스트 가능한 인수 조건
12. Non-Goals
13. 기술적 제약
14. Open Questions
15. 성공 조건

Non-Goals:
- TypeScript 도입
- 백엔드 코드 변경
- API 계약 변경
- 데이터베이스 변경
- 승인되지 않은 패키지 설치
- 이미지에 없는 기능 추가
- 관련 없는 리팩터링

작성 규칙:
- 기능 요구사항에는 FR-001 형식의 번호를 붙인다.
- 인수 조건은 관련 FR 번호를 참조한다.
- 확인되지 않은 사항을 임의로 결정하지 않는다.
- Context7에서 프로젝트 버전에 맞는 JavaScript 사용법을 확인한다.
- 아직 구현하지 않는다.

먼저 초안을 보여주고 승인을 기다려라.
